# Q10 strict source-only cross-stock transfer — pre-fit frozen protocol

This is a five-fold held-out-stock retrospective transfer experiment on the finalist cheap baseline B1 history-XGBoost and finalist neural S0 GRU, with seeds 7/17/29. FQ4 context32 Transformer was worse than S0 on the frozen full-denominator comparison and is not retained as a transfer finalist. No held-out-stock label enters training, normalization, checkpoint selection, context choice, thresholding, or calibration.

For each held-out stock, the four other stocks supply exactly 200,000 Jan–Mar context128-eligible causal training endpoints **each**, selected by the frozen Q8 source rule, and April source-only dev. First choose one of 8/32/128 contexts using only those four source stocks' published Q8 April stock/day GRU seed-mean ICs; take the maximum equal-source-stock/date mean and break ties within 1e-6 toward shorter context. Q8 per-stock dev scores are a source-only model-selection proxy for the pooled transfer model. The global five-stock Q8 context choice is not used for this fold.

After that source-only context choice, take the trailing chosen context from the same 128-state source windows. Only Jan–March source train and April source dev arrays are loaded; source June/Sep/Nov outcomes are not loaded for fitting. Pool the four source stocks, fit fixed FQ2 XGBoost and one-layer hidden-64 GRU with the formal 60-epoch/patience-8 and seeds. B1 and S0 see the same pooled train/dev history; GRU normalization, target scaling and April early stopping use source stocks only. No held-out Jan–April labels are loaded into fit data. Held-out June/Sep/Nov scoring rows are constructed only after model selection, from the same context128-eligible original-event endpoints as Q8; the held-out labels are used solely for retrospective scoring. Verify endpoint identities against Q8 receipts.

The shared context is selected by source GRU April IC, so it is a neural-favoring source-only choice rather than separate optimal tuning for B1. Report that asymmetry with the paired result; do not reselect from held-out outcomes or retune B1 after seeing transfer scores.

Publish all five folds, each seed, common stock/day denominators, paired IC, training-cap flags, model hashes, fit/inference cost, failures and null/negative results. Compare the transfer and within-stock Q8 rows only descriptively because model training populations differ. All five stocks and evaluation dates have prior researcher exposure, so even strict source-only folds are not independent or prospective confirmation. Private fitted models, row predictions and licensed data remain outside Git. The frozen visible-crossing diagnostic on selected finalists follows Q10 before the final research package.

The design was drafted before Q8 outcomes and frozen after the completed Q8 checkpoint, remote-SHA readback, and latest reviewer-control readback. The Q8 global April choice was 128 states, but it is not used in the per-fold source-only context choice. No Q10 fold has been fit at this protocol freeze.
