## Fixed calculation

- Match each receipt to one `matchOrders` call at its actual destination contract; reject missing/paginated logs, input/event count disagreement and nonunique maker assignment. A maker input consumes exactly one maker `OrderFilled`; `OrdersMatched` and the taker input identify the active order. Print token, side and size must match the taker event. Print price is compared exactly but is not assumed to be a per-leg price. The gross maker price uses receipt assets: BUY = maker collateral / taker shares; SELL = taker collateral / maker shares. Values use the event's six-decimal asset units. Fee is excluded from gross values and reported separately as raw event units.
- For each selected-token passive leg, let `r` be the printed trade's collector receive timestamp; shared by legs from that print, without asserting a common match time. Take the latest raw same-token `best_bid_ask` with `recv_ms < r`, and latest with `recv_ms <= r + 5000`. At each endpoint, evaluate the chosen raw row as `0 < bid < ask < 1` using finite `Decimal`. Do not fall back after an invalid quote. Differing quotes tied at the selected receive timestamp are ambiguous. Known receive clock reversal within the evaluation window and an endpoint past scheduled market end exclude the leg.
- Primary endpoints must each be at most 1000 ms old. The sole sensitivity uses 250 ms. For passive direction `d` (+1 BUY, -1 SELL), per-share cents: `G=100*d*(m_obs-q)`, `D=100*d*(m_obs+5-m_obs)`, `N=100*d*(m_obs+5-q)=G+D`. Failure remains NA, with reason, never zero. Age sensitivity compares both full denominators and the shared eligible legs.
- Report counts of fixed prints, receipt joins, selected-token legs, eligible legs/prints/markets and failure reasons; share-weighted means and ranges of G/D/N overall and by market; largest-leg removal; 250 ms sensitivity.
